Selamat datang di Sahabat SSH

Sahabat SSH menyediakan berbagai layanan tunneling, seperti SSH, Trojan, VMess, dan VLess.

Halaman ini memuat dokumentasi API (Application Programming Interface) / REST API yang disediakan oleh Sahabat SSH. API ini memungkinkan kamu mengintegrasikan aplikasi atau sistem kamu secara langsung dengan layanan Sahabat SSH untuk mengelola akun dan berbagai fitur secara otomatis, cepat, dan efisien.

Base URL

https://api.sahabatssh.com/v2/

Sandbox URL

https://api-sandbox.sahabatssh.com/v2/

Untuk melakukan uji coba sebelum bertindak aktif ke layanan Sahabat SSH, kamu dapat menggunakan Sandbox Mode.

Dengan menggunakan API Sahabat SSH, proses seperti pembuatan akun, pengelolaan layanan, pengecekan informasi, hingga otomatisasi lainnya dapat dilakukan tanpa perlu mengakses panel secara manual.

Autentikasi

Semua endpoint API Sahabat SSH membutuhkan api_key yang valid. API key ini dipakai untuk mengenali user, memeriksa akses, dan menjalankan validasi keamanan seperti IP whitelist.

Rahasiakan API Key kamu

Jangan pernah membagikan API Key kepada pihak yang tidak kamu kenal. API Key dapat digunakan untuk mengakses akun kamu tanpa konfirmasi. Untuk meningkatkan keamanan, aktifkan fitur IP Whitelist agar hanya alamat IP tertentu yang dapat menggunakan API Key tersebut.

Metode Pengiriman API Key

Method Cara Kirim Contoh
GET Kirim api_key melalui query string pada URL. ?api_key=ISI_API_TOKEN
POST Kirim api_key melalui body application/x-www-form-urlencoded. api_key=ISI_API_TOKEN

Contoh GET 

curl --location 'https://api.sahabatssh.com/v2/account/detail?api_key=ISI_API_TOKEN'

Contoh POST 

curl --location --request POST 'https://api.sahabatssh.com/v2/create/ssh' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'api_key=ISI_API_TOKEN' \
--data-urlencode 'id=123' \
--data-urlencode 'type=monthly' \
--data-urlencode 'username=sshbaru01' \
--data-urlencode 'password=Password123'

API Key Validasi

  • API Key harus sesuai dengan akun yang terhubung ketika ingin di jalankan.
  • Kesalahan ketika API yang di proses salah atau tidak benar akan mengalamani kode error 401.
  • IP yang tidak terdaftar saat menjalankan api dan mengaktifkan IP Whitelist akan memberikan kode error 403.
  • Beberapa endpoint juga memeriksa apakah akun atau server yang diminta memang boleh diakses oleh API key tersebut.

Cara Terbaik Menjaga API Key

  • Simpanlah API Key di backend atau environment variable, jangan pernah menaruh di frontend publik.
  • Aktifkan fitur IP Whitelist jika request hanya berasal dari server pribadi, bot, atau server lain yang bersifat private.
  • Jangan menaruh API Key langsung di dalam client aplikasi.
  • Jika informasi API Key mengalami kebocoran atau ada orang lain mengetahuinya, segera generate API Key dari akun kamu.

Error Terkait Autentikasi

Code Pesan Keterangan
400 Parameter api_key wajib diisi. Muncul saat parameter api_key tidak di isi atau kosong.
401
API key tidak valid.
User API tidak ditemukan.
 Muncul saat API Key tidak cocok atau tidak ditemukan.
403 IP kamu tidak masuk whitelist. Muncul saat fitur IP Whitelist aktif dan IP yang mengirim tidak terdaftar.

Format Response

Semua endpoint API Sahabat SSH akan mengembalikan response dalam format JSON.

Struktur

Response memakai 4 field utama:

Field Tipe Keterangan
status boolean Menandakan request atau permintaan berhasil atau gagal.
code integer Kode response API, biasanya mengikuti hasil validasi endpoint.
message string Respon pesan ringkas yang menjelaskan hasil dari request.
data object Berisi data utama yang direquest atau yang diminta seperti detail rincian akun dan lainnya.

Contoh Response Sukses 

{
  "status": true,
  "code": 200,
  "message": "Detail akun berhasil diambil.",
  "data": {
    "ip_address": "123.123.123.123",
    "ip_whitelist": false,
    "account": {
      "username": "contohuser",
      "name": "Contoh User",
      "email": "[email protected]",
      "balance": "10000"
    }
  }
}

Contoh Response Gagal 

{
  "status": false,
  "code": 400,
  "message": "Parameter api_key wajib diisi.",
  "data": {}
}

Response Code

Berikut ini kode response yang akan muncul saat melakukan permintaan atau request.

Code Status Keterangan Contoh Kondisi
200 Success Request Berhasil. Permintaan berhasil diproses dan akan menampilkan data sesuai endpoint API yang dijalankan.
400 Bad Request Parameter atau body request tidak lengkap, kosong, atau format input tidak sesuai aturan endpoint. `api_key` kosong, `type` salah, `quota` tidak valid, atau parameter wajib tidak dikirim.
401 Unauthorized API Key tidak valid atau tidak ditemukan pada data user. API Key pada parameter `api_key` tidak ditemukan`.
403 Forbidden Request atau permintaan ditolak. Karena IP belum didaftarkan di dashboard API Key.
422 Unprocessable Entity Request terbaca dengan baik, tetapi ada penolakan karena suatu alasan dari validasi yang dilakukan oleh server. Bisa disebabkan oleh server sedang penuh, saldo tidak mencukupi, username sudah terpakai, email belum terverifikasi, atau fitur yang tidak tersedia pada layanan tertentu.
